# B29, distance-one fills

Starting at qualified main a1d3955, replace the overlapping-copy sequence by a byte fill only for distance 1 and matches of at least 32 bytes in the KLZ/KLZH2 copy routine. The produced frames and decoder format are unchanged. Stock and candidate built with the same Makefile defaults on Apple M5.

Tested six inputs at L1/L2/L3, 11 scored A/A/B triplets plus warmup. All 648 full CLI file-to-file trials restored exact bytes and the same frames. Coverage counters run separately on stock-generated frames show which observations can reasonably be attributed to the modified code. On the synthetic run-heavy L1 case the new path covered 524,287 of 786,432 bytes; the raw decoder gained 241.6% in paired CPU throughput (32 decodes per batch). On MR L1 it covered 110,063 of 1,048,576 bytes; raw decode gained 3.7% amid a much larger same-binary spread. Two naturally routed file/level cells had zero eligible fills. Real-source raw decode changes ranged from −12.3% to +4.8%, while CLI results were mixed. Keep the synthetic gain and evidence. Decline a broad default change.
