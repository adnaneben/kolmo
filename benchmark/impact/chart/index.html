How these numbers were made

Ratio = input bytes ÷ frame bytes, summed over the chosen files (53 real files cut to ≤ 4 MiB, 15 kinds; or the 62 small text cuts of 16 KiB–1 MiB). Combined speed = input MB ÷ (compress seconds + decompress seconds), so a file that takes 1 s each way at 100 MB scores 50 MB/s; the tooltip and the table give compress and decompress speed separately.

Times are whole kolmo processes (start-up included) on a 10-core Apple M5, one at a time, at load below 20; the levels are timed at load 1.4–3.0. Sizes are exact and identical at 1 and 10 threads. A file a feature did not change keeps the level's frame and timing. A T10 point is shown only where every file the feature changed has its own T10 timing. Features that use the lexer or priors write streams only the research decoder reads.
